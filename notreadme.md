# ПринтПлюс — шаблон приложения ГИА

Универсальная заготовка desktop-приложения на Python 3.11+, Tkinter/ttk, PostgreSQL и SQLAlchemy ORM. Текущий вариант предметной области — типография «ПринтПлюс», работа с партнерами.

Код специально сжат для ГИА: модели лежат в `models/__init__.py`, бизнес-функции в `services/__init__.py`, весь интерфейс в `ui/app.py`.

## Создание базы PostgreSQL

```sql
CREATE DATABASE gia_printplus;
```

## Настройка .env

Создайте файл `.env` рядом с `main.py`:

```env
DATABASE_URL=postgresql+psycopg://postgres:postgres@localhost:5432/gia_printplus
```

В проекте используется драйвер `psycopg`. Если на экзамене требуют именно `psycopg2-binary`, можно заменить зависимость в `requirements.txt` и указать `postgresql+psycopg2://...` в `DATABASE_URL`.

## Установка зависимостей

```bash
pip install -r requirements.txt
```

## Создание таблиц

```bash
python -m database.init_db
```

## Заполнение тестовыми данными

```bash
python -m database.seed
```

## Запуск приложения

```bash
python main.py
```

## Что реализовано

- авторизация пользователя;
- список партнеров;
- поиск по названию, руководителю, телефону, email и ИНН;
- фильтрация по типу партнера;
- сортировка по названию, рейтингу и скидке;
- добавление партнера;
- редактирование партнера;
- история продаж партнера;
- динамический расчет скидки по сумме продаж;
- отдельный сервис расчета материала;
- подключение к PostgreSQL через `DATABASE_URL`;
- SQL-скрипты создания и наполнения таблиц;
- инструкция для ручного импорта данных из `.xlsx`.

## Какие файлы сдавать

- исходный код приложения;
- `requirements.txt`;
- `.env.example`;
- SQL-скрипты из папки `scripts`;
- ER-диаграмму отдельно;
- ресурсы логотипа и иконки, если они используются.

## Универсальная настройка варианта

Основные подписи, цвета, заголовки, поля формы, параметры поиска, сортировки и пороги скидок вынесены в `config/domain_config.py`. Для нового варианта ГИА обычно достаточно адаптировать этот файл, модели/таблицы и стартовые данные.

## Импорт Excel

Основной ручной импорт можно выполнять через pgAdmin. Порядок заполнения таблиц и контрольные SQL-запросы описаны в `scripts/import_notes.md`. В `scripts/import_xlsx_example.py` есть небольшая заготовка для чтения Excel через `openpyxl`.
